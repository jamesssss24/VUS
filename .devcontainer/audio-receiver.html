On-demand streaming quickstart

To stream desktop audio from a Linux sender, run one of these commands on that machine. Permit the sender port through your firewall only on networks you trust.

FFmpeg HTTP (MP3)

Capture the default PulseAudio or PipeWire source and listen on port 8080.

ffmpeg -f pulse -i default -c:a libmp3lame -b:a 128k -content_type audio/mpeg -f mp3 -listen 1 http://0.0.0.0:8080/stream

VLC HTTP stream

Use VLC to encode the default PulseAudio source as an MP3 stream.

cvlc pulse://default --sout '#transcode{vcodec=none,acodec=mp3,ab=128,channels=2,samplerate=44100}:http{mux=mp3,dst=:8080/stream}'

Connect to the sender

Choose HTTP audio or Icecast in the dashboard and enter the sender's reachable address, for example http://192.168.1.100:8080/stream. Browser playback of remote streams depends on network access; visual analysis also requires the sender to allow cross-origin access.
